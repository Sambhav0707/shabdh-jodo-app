# level3b doubts (te)

- Sandhi groups with archaic or textbook-only forms: గసడదవాదేశ (వాడుగొట్టె, ఉప్పుగప్పురంబు, కాలుసేతులు), త్రిక (అక్కన్య, ఇక్కాలము, అమ్మహిమ), యడాగమ (సెలయేరు), పుంప్వాదేశ (బంగారపుగాజులు, పగడపుదీవి). A teacher should confirm these.
- అత్వ సంధి examples (రామయ్య, సీతమ్మ, అన్నయ్య): some textbooks file these under other sandhi types.
- సమాసం labels: some grammars classify రూపక, షష్ఠీ తత్పురుష and సంభావనా పూర్వపద examples differently.
- ద్వంద్వ (తల్లిదండ్రులు, అన్నదమ్ములు) and గసడదవాదేశ (కూరగాయలు) are close in theme. Don't put them in the same puzzle.
- Hidden-word groups (పులిహోర, కుక్కర్, మేకప్, మెడల్, ఆరుబయట, అమ్మకం…) work only on spelling. Check that players see the hidden word.
- Palindromes: కనక and కటిక are less familiar standalone forms.
- Tadbhava pairs (కంబం←స్తంభం, బొమ్మ←బ్రహ్మ, ఆన←ఆజ్ఞ, గారవం←గౌరవం, అక్కరం←అక్షరం) are textbook pairs, but some are rare in modern use.
- Place-name tiles are truncated stems (సూర్యా, హైదరా, అనకా, బోయిన్, మలక్, జియా, చిలకల), so check the spellings.
- Some compound halves are colloquial or uncommon: పులి + హోర (a pun), మాయ + రోగం, బుర్ర + బద్దలు, అగ్గి + పిడుగు, నేల + గుమ్మడి/వేము, చలి + పులి, లక్ష్మీ + బాంబు.
- Idiom verb tiles (కళ్ళు/నోరు/కాలు/గుండె/ఒళ్ళు ___) reuse the same verbs (జారు, పడు) across groups, so there's a risk of overlap within a puzzle.
- ___ + వాడు (పాల, పేపరు, పూల) is colloquial. ___ + పాలన includes బ్రిటిష్ and నిజాం.
- ___ + ఏకాదశి (నిర్జల) and ___ + జయంతి (హనుమాన్, అంబేద్కర్) contain loan or Hindi-style forms.
