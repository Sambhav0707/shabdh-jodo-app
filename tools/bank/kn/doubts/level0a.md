# level0a doubts (food/nature/animal/body/health) - for native check
- Many groups are overlapping by design (e.g. ಮಾವು in several fruit groups); dedupe at puzzle build time.
- Loose/subjective groups: "ಕಾಡಿನ ಹಣ್ಣುಗಳು", "ಬೇಸಿಗೆಯ ಹಣ್ಣುಗಳು" (ತಾಟಿನುಂಗು), "ಸಿಹಿ ಹಣ್ಣುಗಳು", "ಹುಳಿ ಹಣ್ಣುಗಳು" (ಕಮರಕ್ಕಿ).
- Spellings to verify: ಕೊಳ್ಳೆನರಿ, ಕೊರಲೆ, ಹಾರಕ, ಊದಲು, ಬರಗು, ಮುರುಗಲು, ಕವಳೆ, ಬೆಟ್ಟದ ನೆಲ್ಲಿ, ಅಮಟೆಕಾಯಿ.
- Dish names: ಗೋಳಿಬಜೆ, ಪುಂಡಿ, ಕೋರಿ ರೊಟ್ಟಿ, ಕಡಂಬುಟ್ಟು, ನೂಪುಟ್ಟು, ಪಾಪುಟ್ಟು, ಅಕ್ಕಿ ಒಟ್ಟಿ, ಜುಣಕ, ಗಿರ್ಮಿಟ್, ಬಾದುಶಾ, ಪುಳಿಮುಂಚಿ.
- Synonym groups ("... ಹೆಸರುಗಳು"): ಪಂಚಮುಖಿ (lion), ಘೋಟಕ, ವಿಟಪಿ, ದ್ವಿಜ, ಕೌಮುದಿ, ಜಲದ, ಅಬ್ಧಿ - check these are acceptable synonyms.
- Animals/birds: ಹರಟೆಮಲ್ಲ/ಸೂರಕ್ಕಿ/ಕಾಜಾಣ/ಗೀಜಗ identification; ಸಿಕ್ರೆ ಹಕ್ಕಿ, ಕಟ್ಟಿಗೆ ಹಾವು, ಕಟ್ಟುಹಾವು, ಕೊಳಕುಮಂಡಲ spelling; fish: ಕಾಣೆ, ಬೂತಾಯಿ, ಗೆಂಡೆ, ಕೊರಮೀನು.
- Health: ಲೇಹ್ಯ, ವಟಿ, ಚೂರ್ಣ (Ayurveda terms), ಬೆವರುಸಾಲೆ, ಗಂಟಲುಬೇನೆ; "ವಿಟಮಿನ್ ಎ" style tiles use spaces.
- Some words spelled with ZWNJ (e.g. ಬೀಟ್‌ರೂಟ್, ಸ್ಟ್ರಾಬೆರಿ) - loanword spellings may vary.
- Colour-of-flower groups (ಕೆಂಪು/ಬಿಳಿ ಹೂಗಳು) include modifier+noun tiles like "ಬಿಳಿ ಗುಲಾಬಿ".
