# Doubts: kn level0b

- Many "synonym" groups (e.g. ಸುಖದ ಪದಗಳು, ಆಳುವವನ ಹೆಸರು) lean toward level 1; consider moving.
- Names were deliberately indirect to avoid containing own words; some names are slightly awkward.
- ಚೌಕಾಬಾರ / ಪಗಡೆ / ಅಳಿಗುಳಿಮನೆ: regional game names, verify spelling.
- ಹಾವುಏಣಿ: usual Kannada name may be "ಹಾವು ಏಣಿ" or "ಹಾವು-ಏಣಿ".
- ಕಲ್ಲಿದ್ದಲು, ಸೌದೆ grouped as fuels; fine but check.
- ಬೇವಿನ ಹೊಗೆ in the mosquito group: folk usage, verify.
- ಬುಲಾಕು / ನತ್ತು / ಬೆಂಡೋಲೆ: jewellery terms vary by region.
- ಸಂಡಿಗೆ, ಹಪ್ಪಳ spellings (ಸಂಡಿಗೆ vs ಸಂಡಿಗೆ) fine; ವಡಾಮ್ removed? check no dubious leftovers.
- Kannada month groups (ಜ್ಯೇಷ್ಠ, ಭಾದ್ರಪದ, ಆಶ್ವಯುಜ): standard spelling assumed.
- ಬಾಸಿಂಗ, ಒಡ್ಯಾಣ, ಹಸಿರುಬಳೆ in bride group: regional, verify.
- ಹಿಂದಿನ ಕಾಲದ ವಸ್ತುಗಳು / ಹೈನುಗಾರಿಕೆ groups are loose; may allow other words.
- ಪ್ಯೂನ್, ಇಂಜಿನಿಯರ್, ಟೈಪಿಸ್ಟ್: loanword spellings (ಇಂಜಿನಿಯರ್ vs ಎಂಜಿನಿಯರ್).
- Spaces inside some tiles (ಬೇವಿನ ಕಡ್ಡಿ, ಕಾಲ್ಚೈನು) assumed fine; ZWNJ words like ಪಾಸ್‌ಬುಕ್ use U+200C.
