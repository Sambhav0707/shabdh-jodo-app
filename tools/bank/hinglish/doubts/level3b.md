# Doubts: level3b (Hinglish compounds/idioms/rhymes)
- Many "Verb-object" idiom groups (e.g. "Naak ___", "Dum ___", "Sach ___", "Waqt ___") have multi-word tiles like "ka jala"; check fit and fairness.
- Idiom prefix groups overlap heavily with each other (many share verbs like lagana/dena); possible cross-group ambiguity in a puzzle.
- Rhyme groups: spelling is Roman approximations (e.g. "khwaab" vs "jawaab"); ensure rhyme reads clearly. Weaker ones: 'sanam' (gham/kam/dam), 'musafir', 'chalaak', 'sapna'.
- Culture groups (Ramayan/Mahabharat, deity names, surnames like "___ Singh") are family culture/people; keep only if wanted.
- Compounds with loose validity: "___ + ana" (mast/mard/dost/shah/aashiq), "___ + pasand", "___ + stan", "___ gaon" (Gur, Gore, Male), "___ pur (aur sheher)" (Sola, Kolha are clipped).
- Slang groups ("Mumbai slang", "Gen-Z desi slang", "Ekdum mast scene") are fuzzy synonym sets.
- Sounds groups (onomatopoeia) are spelling-dependent; "Comic ke dhamaake" mixes English.
- Some groups may overlap with writer (a) synonyms or with names like "Jaan ___" vs "Jaan + ___".
