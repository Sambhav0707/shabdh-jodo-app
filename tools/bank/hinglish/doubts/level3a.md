# level3a doubts
- Later synonym groups (Mausam..Aish block, Roshni..Thakaan block) were written fast; several mix Hindi/Urdu/English words and some tiles are near-duplicates in meaning. Review before use.
- Words-with-multiple-meanings groups ("'X' ke matlab") use English meanings as tiles; some meanings overlap (e.g. 'Kam', 'Lena', 'Dena' verbs, 'Sheel', 'Sandhi'). Verb groups are weak.
- Some groups use English tiles (life, time, money) as "common English" synonyms; may be too easy for level 3.
- "Hindi/English dono mein shabd" groups (pal, gum, dam, gun, tin; pet, tan, sir, man, gal; main, hum, us, to, do, so) are loose; tin/gal are doubtful.
- Loanword groups (Hindi se English mein aaye ...) may overlap in words across groups (guru, loot, bungalow, pyjamas, shampoo); check cross-group duplicates.
- Indian English groups (Brand jo cheez ban gaye, train/office/school words) include words like tiffin, xerox, tubelight appearing in more than one group.
- Mythology name groups (Shiv, Krishna, Ganga...) use capitalized proper nouns; Karna/Bhishma/Arjun ones are fine but "Durga" and "Lakshmi" lists contain looser epithets.
- Some groups have only 4 words (accepted).
